# Mr.A AI

Mr.A is an Android AI assistant focused on a clean chat experience, Myanmar-friendly responses, voice input/output, and context-aware Smart UI Cards.

## Current build
- Android 36 / target SDK 36
- Kotlin + Jetpack Compose + Material 3
- Gemini / ChatGPT / DeepSeek provider options
- Voice input and voice output
- Chat history
- Smart UI cards for weather, calculator, stats, tasks, reminders, translation, code, and support
- Developer profile and KPay / Wave Money support page
- Keyboard-safe chat layout
- GitHub Actions debug APK build with an automatically generated debug keystore
